# Возврат видеокэша c.youtube.com в обычный TCP-профиль YouTube

## Требования и проверка

| Требование | Изменение | Проверка |
|---|---|---|
| В раздельных TCP-профилях соединение с известным именем c.youtube.com или его поддоменом использует yt_tcp | Правило по имени проверяется перед правилом по IP и устаревшим списком GV. При обновлении списков старый суффикс удаляется из YT_GV | tests/test_cyoutube_gv.sh проверяет конфиг до и после обновления списков, googlevideo.com, регулярный YouTube и QUIC |
| DNS-ответ для видеокэша c.youtube.com сам по себе не добавляет IP в gv_tcp | Учитывается источник адреса при обработке ответа и восстановлении наблюдений. Один IP может также принадлежать googlevideo.com | TestYouTubeCacheDoesNotPublishGVAddress проверяет DNS, восстановление и общий адрес |
| Добавить Kurdt_Kobain в благодарности, текст подписи согласовать с владельцем | Имя добавлено в README, CLI и карточку веб-панели | Имя проверено во всех трёх местах. Подпись ожидает согласования |

Проверки выполнены локально. Ранее накопленный файл IP не хранит имён, а ключ youtube.com в истории стратегий не содержит исходного поддомена. Задним числом эти данные не разделяются.
