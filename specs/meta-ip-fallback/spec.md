# Резервные адреса Meta для Keenetic

## Требования и критерии приёмки

1. Запросить адреса всех управляемых имён, включая static.xx.fbcdn.net и scontent.xx.fbcdn.net. Сначала проверить собственные кандидаты каждого имени с роутера.
2. При нехватке адресов до установленного лимита проверить уникальные подходящие IP из числа успешно проверенных в первом проходе. Результат не зависит от порядка имён. Сохранить предпочтение собственным рабочим IP.
3. Для заимствования обязательны принадлежность диапазону Meta и ответ нужной службы на целевом имени. Для статических файлов сверить содержимое. При выключенной пробе заимствование отключено.
4. Сохранить прежние записи, если замены отсутствуют или установить новый IP не удалось. Учитывать частично рабочие наборы, повторный запуск и отказ пользователя от статических записей.

## План и проверка

- Согласовать имена клиента, резолвера и удаления записей.
- Отделить проверку и сбор кандидатов от применения записей. Использовать обычные средства Entware.
- Проверить на подставных curl/ndmc успешную замену, ложный HTTP-ответ, предпочтение собственных адресов, отсутствие кандидатов и ошибку записи. Проверить сетевые пробы с роутера.

## Результаты проверки 22.11.2026

- Рабочий VPS со старым списком разрешённых имён дал на роутере 23 подходящих пары для 12 имён. Пары для двух имён fbcdn из этого пула не подошли.
- Обновлённый обработчик /resolve, запущенный локально с реальными DNS-запросами, вернул кандидатов для всех 14 имён. В итоговом прогоне на Keenetic 26 пар прошли проверку, в том числе 12 пар во втором проходе. Для обоих имён fbcdn подошёл 57.144.248.128. Команды записи DNS в прогоне выполнял файловый стаб.
- Для static CDN проверялся SHA-256 файла, для scontent проверялся характерный ответ обработчика на неподписанный URL. Загрузка пользовательского медиа по подписанному URL в тест не входила.
- test_meta_ip_fallback.sh проверяет замену и дополнение записей, неверный файл с HTTP 200, дедупликацию, временную сетевую ошибку, совместно используемый IP, отказ ndmc и повторный запуск. Проверены штатные тесты opt-out, c10r, фонового обновления, очистки, AdGuard Home и пакет vps-relay.
