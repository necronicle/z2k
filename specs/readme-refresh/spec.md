# Feature Specification: Переработка README

**Created**: 2026-11-16
**Status**: Implemented locally; awaiting owner review

## User Scenarios & Testing

### US1 — Первый запуск (P1)
Читатель узнаёт назначение, требования и ограничения до установки, выполняет установку и находит панель.
**Acceptance**: README содержит последовательные разделы требований, установки и первого запуска, точную прежнюю команду установки и оглавление.

### US2 — Настройка и помощь (P2)
Читатель находит действие по симптому и переходит к подробному руководству.
**Acceptance**: Есть таблица частых проблем, выгрузка файла диагностики из веб-панели, ссылки на настройки и технические подробности.

## Requirements

- FR-001: Дословно сохранить: «Данный проект предназначен для исследования сетевых протоколов и изучения работы систем анализа трафика. Используется исключительно в учебных целях.»
- FR-002: Сохранить штатную команду установки, адреса, реквизиты и всех участников благодарностей. По последующему уточнению владельца удалить рекомендации прямого запуска внутренних скриптов и ручной правки конфигурации.
- FR-003: Сохранить существенные инструкции, ограничения, предупреждения удаления и оговорки о проверенности в связанных документах.
- FR-004: Сократить основной README, добавить оглавление и единый пользовательский маршрут.
- FR-005: Менять только документацию; не запускать установку, не публиковать и не менять инфраструктуру.

- FR-006: По уточнению владельца README и два руководства используют исследовательскую терминологию без формулировок о преодолении ограничений доступа. Обязательная плашка остаётся дословной. Команды, пути и параметры не переименовываются.

- FR-007: Основной пользовательский путь проходит через веб-панель. Помощь: «Диагностика» → «Сводка z2k-diag» → «Скачать файл» → отправка вложением. CLI — только отдельная дополнительная справка; прямое управление init-скриптами и ручное редактирование файлов не рекомендуются. Команды подготовки Entware, первичной установки и настройки Windows сохраняются как необходимые отдельные случаи.

- FR-008: Включение TCP timestamps на каждом Windows-компьютере — обязательный самостоятельный шаг установки до первого запуска, независимо от наличия симптомов. Команда выполняется в Windows от имени администратора. Отключение показано отдельно как отмена настройки.

## Success Criteria

- SC-001: Основной README не длиннее 350 строк (исходно 840).
- SC-002: Все относительные ссылки и якоря в новых/изменённых пользовательских документах разрешаются.
- SC-003: Установочная команда совпадает с исходной; обязательный текст и имена сохранены.
