# Запасные адреса эндпоинтов Cloudflare WARP.
#
# ЗАЧЕМ ЭТОТ ФАЙЛ. Cloudflare выдаёт устройству адреса при регистрации, и они
# бывают целиком в диапазоне, который режут: у человека из поля вся регистрация
# оказалась в 162.159.192.0/24, и WARP не поднимался вовсе. Перерегистрация не
# помогает — со второй попытки приходит другой адрес из того же блока
# (воспроизведено: 162.159.192.4 -> 162.159.192.7).
#
# Ключ к адресу НЕ привязан: любой узел принимает ту же регистрацию. Поэтому,
# когда выданные адреса мертвы, движок идёт по этому списку.
#
# ПОЧЕМУ ФАЙЛОМ, А НЕ В КОДЕ. Адреса стареют: 162.159.193.x работал, а к концу
# 2024 перестал. Зашитый в бинарник список потребовал бы релиза с пересборкой
# под пять арок ради одной строки. Здесь достаточно правки списка.
#
# Формат: один адрес на строку, «#» — комментарий. Порт подставляет движок
# (2408 и запасные порты из регистрации). Кривые строки пропускаются молча.
#
# Проверено с роутера владельца 2026-08-25, регистрация на 8.6.112.0:
#   8.6.112.1      handshake ok
#   8.47.69.1      handshake ok
#   188.114.96.1   handshake ok
#   188.114.97.1   handshake ok
#   162.159.195.1  no handshake   — в список не берём
#   162.159.193.10 no handshake   — умер в конце 2024, не берём
