# z2k — Zapret2 для Keenetic

z2k — инструментарий на базе zapret2 для исследования сетевых протоколов и систем анализа трафика на роутерах Keenetic с Entware. Включает автоматический подбор параметров обработки пакетов, сетевую диагностику и веб-панель.

> Данный проект предназначен для исследования сетевых протоколов и изучения работы систем анализа трафика. Используется исключительно в учебных целях.

## Возможности

- **Сайты, YouTube и Discord.** Готовые списки доменов и стратегии для TCP и QUIC. Автоподбор запоминает найденные варианты между перезапусками.
- **Telegram.** Прозрачное подключение для устройств в сети без настройки приложения; включается при установке или в меню `[T]`. На Realtek Lexra недоступно.
- **Игровой режим WARP.** Раздельная маршрутизация трафика игр и сервисов через туннель. Устанавливается по желанию; игры и устройства выбираются в панели.
- **Свои домены и исключения.** Можно выбрать домены для обработки и исключить отдельные домены, адреса и подсети.
- **Веб-панель.** Статус, настройки, диагностика, обновление и удаление. Работает без загрузки ресурсов из интернета.
- **IPv4 и IPv6.** Поддержка обоих семейств адресов; ограничения отдельных режимов описаны в руководстве.

Движок — [zapret2 v1.0.7 в сборке z2k](https://github.com/necronicle/zapret2-z2k), основанной на bol-van/zapret2. Он устанавливается и обновляется вместе с z2k, компиляция на роутере не нужна.

## Перед установкой

Понадобятся роутер Keenetic, установленный Entware и доступ к его терминалу. Подготовка USB-накопителя и обязательных компонентов прошивки описана ниже. На каждом Windows-компьютере обязательно включите TCP timestamps — [шаг 4](#4-windows-обязательно-включить-tcp-timestamps).

**На Realtek Lexra работает обработка пакетов, но недоступны Telegram, детектор и проверка подписи обновлений:** для этой разновидности MIPS нет сборок компонентов на Go. Подробнее — [ограничения Lexra](docs/user-guide.md#telegram).

## Установка

Команды ниже выполняются в терминале Entware на роутере.

### 1. Компоненты Keenetic

**«Модули ядра подсистемы Netfilter» нужны на ЛЮБОЙ прошивке Keenetic** — по умолчанию они не предустановлены, и без них z2k не запустится. Их нужно доустановить в веб-интерфейсе Keenetic (раздел «Изменить набор компонентов»):

1. **«Модули ядра подсистемы Netfilter»** — обязательно, на всех прошивках и роутерах.
2. **«Протокол IPv6»** — нужен только на старых прошивках (и только если вы используете IPv6). На новых прошивках IPv6 уже включён по умолчанию, и такого пункта в списке может не быть.

На части прошивок пункт «Модули ядра подсистемы Netfilter» появляется в списке только после того, как выбран компонент «Протокол IPv6».

### 2. Entware и зависимости

Подготовьте USB-накопитель и установите Entware по официальной инструкции Keenetic:
https://help.keenetic.com/hc/ru/articles/360021214160

После установки Entware выполните обновление индекса пакетов и установите зависимости:

```bash
opkg update &&
opkg install libcurl curl coreutils-sort grep gzip ipset iptables kmod_ndms xtables-addons_legacy openssl-util
```

В списке явно указаны и `libcurl`, и `curl`. В Entware зависимость `curl` от `libcurl` задана без версии. Если библиотека уже установлена, `opkg install curl` может обновить только саму утилиту и оставить старую библиотеку.

Перед скачиванием установщика проверьте, что `curl` запускается вместе с библиотекой Entware.

```sh
LD_BIND_NOW=1 curl --version
```

Если появляется `undefined symbol: curl_multi_get_offt`, загрузчик нашёл библиотеку `libcurl`, в которой нет нужной функции. Даже если OPKG пишет, что `curl` уже обновлён, переустановите оба пакета из актуального индекса Entware и повторите проверку.

```sh
opkg update && opkg --force-reinstall install libcurl curl && LD_BIND_NOW=1 curl --version
```

Продолжайте установку, когда команда выведет версии `curl` и `libcurl`. Если ошибка сохранилась, для диагностики пришлите вывод `command -v curl`, `opkg list-installed | grep -E '^(libcurl|curl) '` и, если доступна команда `ldd`, вывод `ldd "$(command -v curl)" | grep libcurl`.

<details>
<summary>Если Entware не устанавливается или загрузка пакетов зависает</summary>

#### Если `opkg update` висит или обрывается

У части провайдеров сервер пакетов Entware (`bin.entware.net`) обрывает загрузку на первых десятках килобайт, и `opkg` висит без конца. Возьмите пакеты через зеркало на узле проекта z2k — оно отдаёт только `bin.entware.net` и больше ничего:

```bash
sed -i 's|http://bin.entware.net|http://85.192.60.175/entware|g' /opt/etc/opkg.conf
sed -i 's|http://213.176.74.63/entware|http://85.192.60.175/entware|g' /opt/etc/opkg.conf
opkg update &&
opkg install libcurl curl coreutils-sort grep gzip ipset iptables kmod_ndms xtables-addons_legacy openssl-util
sed -i 's|http://85.192.60.175/entware|http://bin.entware.net|g' /opt/etc/opkg.conf
```

Последняя строка возвращает основной сервер в настройки `opkg`.

Сам установщик z2k ставит и обновляет пакеты через узел и без этого шага.

Стороннее зеркало вместо узла подойдёт, только если у вас стоит полноценный wget (пакет `wget-ssl`): встроенный в Entware busybox wget не умеет https, а по http зеркало ему отказывает.

```bash
sed -i 's|http://bin.entware.net|https://mirrors.bfsu.edu.cn/entware|g' /opt/etc/opkg.conf
opkg update
```

Вернуть основной сервер: `sed -i 's|https://mirrors.bfsu.edu.cn/entware|http://bin.entware.net|g' /opt/etc/opkg.conf`

#### Если Entware не устанавливается

Официальный установщик Entware во время установки сам качает пакеты с того же `bin.entware.net`, поэтому на таких линиях установка обрывается. Для этого случая есть офлайн-установщики: официальный установщик с пакетами внутри, сеть при установке не нужна. Архивы для всех архитектур, инструкция и контрольные суммы — в репозитории [entware-offline](https://github.com/necronicle/entware-offline).

</details>

### 3. Установка z2k

```bash
{ /opt/bin/curl --resolve raw.githubusercontent.com:443:85.192.60.175 -fsSL https://raw.githubusercontent.com/necronicle/z2k/z2k-enhanced/z2k.sh || /opt/bin/curl -fsSL https://raw.githubusercontent.com/necronicle/z2k/z2k-enhanced/z2k.sh; } | sh
```

### 4. Windows: обязательно включить TCP timestamps

**Выполните этот шаг на каждом компьютере с Windows, который будет использовать z2k.** Это обязательная часть установки для Windows, даже если сайты пока открываются.

На самом Windows-компьютере откройте **командную строку от имени администратора** и выполните:

```bat
netsh interface tcp set global timestamps=enabled
```

Часть поставляемых стратегий использует метки времени TCP в тестовых пакетах. Поэтому включение TCP timestamps входит в обязательную подготовку Windows-устройств.

<details>
<summary>Как отменить настройку при отказе от использования z2k</summary>

В командной строке Windows от имени администратора:

```bat
netsh interface tcp set global timestamps=disabled
```

Это отключает TCP timestamps. Не выполняйте эту команду в рамках установки z2k.

</details>

## Первый запуск и веб-панель

1. После установки выберите в меню `[P]` → `[1]` — установить веб-панель.
2. На устройстве в домашней сети откройте `http://ROUTER_IP:8088/`, заменив `ROUTER_IP` локальным адресом роутера.
3. На «Дашборде» проверьте карточку «Состояние». Кнопки запуска, остановки и перезапуска находятся рядом, в «Управлении сервисом».
4. Проверьте нужный сайт на устройстве за роутером. Автоподбору может потребоваться несколько попыток: если сайт не открылся сразу, повторите загрузку страницы.

**Панель по умолчанию без пароля и доверяет домашней сети.** Включить вход с учётными данными веб-интерфейса Keenetic можно в меню `[P]` → `[6]`. Панель работает по HTTP; подробности — [вход по паролю](docs/user-guide.md#вход-по-паролю).

Дальше всё настраивается в панели:

| Задача | Где настроить |
|---|---|
| Добавить домен для обработки | «Доп. домены» — [формат и правила](docs/user-guide.md#пользовательские-домены) |
| Убрать сайт или адрес из обработки | «Исключения» — [домены, IP и подсети](docs/user-guide.md#раздел-исключения) |
| Проверить сайт и получить сводку | «Диагностика» — [доступные проверки](docs/user-guide.md#раздел-диагностика) |
| Посмотреть или закрепить стратегию | «Стратегии» — [автоподбор и ручной выбор](docs/user-guide.md#раздел-стратегии) |
| Включить туннель для игр | «WARP»: установить, выбрать игры и включить — [подробнее](docs/user-guide.md#игровой-режим-warp) |
| Изменить сетевые режимы | «Режимы» — [помощь с видео YouTube](docs/user-guide.md#видео-youtube-которое-не-начинается) |

Списки доменов обновляются ежедневно в 04:00, проверка обрыва на 16 КБ запускается в 03:30. Пользовательские домены сохраняются при обновлении списков.

## Если что-то не работает

| Симптом | Что сделать |
|---|---|
| Сайт не открылся сразу после установки | Повторите загрузку несколько раз: автоподбору нужны попытки соединения. Если не помогло — проверьте домен в «Диагностике» |
| Не открывается отдельный сайт | Проверьте, есть ли он в списках; добавьте его в «Доп. домены», если его там нет |
| Без z2k сервис работал, а с ним перестал | Добавьте его в «Исключения»: сайт — по домену, камеру или приложение без видимого имени — по адресу сервиса |
| На iPhone или Mac работает, на Windows зависает | Проверьте, выполнен ли обязательный [шаг установки для Windows](#4-windows-обязательно-включить-tcp-timestamps) |
| YouTube открывается, но видео не начинается | Проверьте режимы видео; при проблемах с QUIC попробуйте «YouTube без QUIC» — [подробнее](docs/user-guide.md#видео-youtube-которое-не-начинается) |
| Страница обрывается после первых 15–16 КБ | На дашборде запустите проверку «Обрыв на 16 КБ» — [как работает проверка](docs/strategies.md#обрыв-на-16-кб-подбор-имени-по-сетям) |
| Telegram не работает на Realtek Lexra | На этой платформе нет клиента туннеля — [ограничение архитектуры](docs/user-guide.md#telegram) |

### Обратиться за помощью

1. Откройте веб-панель → **«Диагностика»**.
2. В карточке **«Сводка z2k-diag»** нажмите **«Скачать файл»**. Сохранится файл `z2k-diag-….txt` с полным отчётом и логами.
3. Прикрепите файл к сообщению в [Telegram-группе @zapret2keenetic](https://t.me/zapret2keenetic). Укажите модель роутера, провайдера, проблемный сайт и устройство, на котором он не открывается.

Кнопка **«Копировать»** в той же карточке даёт краткую сводку. Для разбора проблемы предпочтителен **файл**: в нём есть полные логи.

## Обновление и удаление

**Обновить z2k:** откройте «Дашборд» веб-панели. Если доступна новая версия, в баннере обновления нажмите **«Обновить»**. Кнопка **«Проверить»** или **«Проверить ещё раз»** запрашивает список версий заново.

При установке файлы загружаются по тегу выбранного выпуска, чтобы версии не смешивались. Свои домены и строки стратегий сохраняются. О проверке подлинности — [подпись обновлений](docs/user-guide.md#подпись-обновлений).

Если обычное обновление не загружается, используйте команду из [раздела установки](#установка). Она же открывает меню, если z2k уже установлен.

**Удалить z2k:** откройте карточку «Удаление z2k» внизу дашборда и нажмите **«Удалить z2k»**. Панель покажет последствия и попросит набрать `УДАЛИТЬ` для подтверждения. Удаление стирает настройки, списки, подобранные стратегии и резервные копии. Пакеты Entware и ключ WARP остаются. Подробнее — [что удаляется](docs/user-guide.md#удаление-z2k).

### Полная зачистка zapret и zapret2

Если после удаления остались процессы `nfqws` или `nfqws2` либо сетевые правила zapret, используйте [скрипт полной зачистки](z2k_cleanup.sh).

**Перед запуском сохраните нужные настройки и списки вне роутера.** Скрипт сразу останавливает процессы, снимает сетевые правила, включая все очереди NFQUEUE в базовых цепочках, и полностью удаляет `/opt/zapret` и `/opt/zapret2`, резервные копии zapret и ключ устройства WARP. Это затрагивает и отдельно установленный zapret.

Выполните в терминале Entware на роутере:

```bash
{ curl --resolve raw.githubusercontent.com:443:85.192.60.175 -fsSL https://raw.githubusercontent.com/necronicle/z2k/z2k-enhanced/z2k_cleanup.sh || curl -fsSL https://raw.githubusercontent.com/necronicle/z2k/z2k-enhanced/z2k_cleanup.sh; } | sh
```
